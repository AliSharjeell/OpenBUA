# Privacy Policy for OpenBUA

Last updated: October 2026

OpenBUA is an open-source, client-side browser extension. We respect your privacy:

1. No Central Data Collection: OpenBUA does not operate external application servers. We do not collect, track, log, or sell your browsing history, personal data, or form inputs.
2. Local Storage: All extension settings, stored profile details, API credentials, and chat histories are stored strictly on your local device via `chrome.storage.local`.
3. Third-Party AI Services: When you initiate a task, required prompts and page contexts are sent directly to the AI provider endpoint you configure (e.g., Google, OpenAI, Anthropic, or a local Ollama instance) via your personal API key. OpenBUA does not intermediate this connection.
4. Permissions: Permissions (such as activeTab, scripting, tabs, and host permissions) are used strictly to inspect elements, execute automation, and extract research data on pages where you explicitly request assistance.

For questions or source code verification, visit the official project repository.
